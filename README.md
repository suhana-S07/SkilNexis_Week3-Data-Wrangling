SkillNexis Week 3 – Data Wrangling with Pandas

Overview

This project is part of my Week 3 Data Analyst Internship assignment at SkillNexis. It focuses on cleaning, processing, and visualizing data using Python.

Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Dataset

The dataset contains workout information, including:

- Duration
- Date
- Pulse
- Maxpulse
- Calories

Tasks Completed

1. Loaded and explored the dataset using Pandas.
2. Checked dataset dimensions, column names, and data types.
3. Identified missing values.
4. Handled missing values in the dataset.
5. Checked for and removed duplicate rows.
6. Filtered records based on pulse values.
7. Created a new "Pulse_Difference" column.
8. Visualized the relationship between pulse and calories using a scatter plot.
9. Verified the cleaned dataset.

Visualization

A scatter plot was created using Seaborn and Matplotlib to explore the relationship between pulse and calories burned.

How to Run

1. Open the ".ipynb" notebook in Google Colab.
2. Upload "data.csv" when prompted, if needed.
3. Run the cells from top to bottom.
